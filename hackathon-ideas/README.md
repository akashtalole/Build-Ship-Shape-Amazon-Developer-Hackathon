# Build, Ship, Shape: Amazon Developer Hackathon — Winning Idea Playbook

Source material: [Rules](https://amazonappdev2026.devpost.com/rules) · [Overview](https://amazonappdev2026.devpost.com/) · [Resources](https://amazonappdev2026.devpost.com/resources)

This folder distills the hackathon's judging criteria into a set of **top candidate winning ideas per prize category**. Each file covers one track/mini-challenge and proposes 3 concepts, scored against the four equally-weighted judging criteria:

1. **Tech Implementation** — effective use of required APIs/SDKs/device capabilities
2. **Design** — a complete, coherent, intuitive product experience for the target device
3. **Potential Impact** — solves a genuine customer need, viable beyond the hackathon
4. **Quality of Idea** — creative, ecosystem-aware use of the required tools

A **friction log** (documenting pain points while building) earns up to a **10% judging bonus** in every track — every idea below recommends keeping one.

## Prize structure ($138,000 total)

| Category | 1st | 2nd | 3rd | Notes |
|---|---|---|---|---|
| [Fire TV](./fire-tv.md) | $25,000 + $15K AWS credits + meeting | $15,000 + $5K AWS credits | $4,000 + $1K AWS credits | Fire OS or Vega OS |
| [Alexa+](./alexa-plus.md) | $25,000 + $15K AWS credits + meeting | $15,000 + $5K AWS credits | $4,000 + $1K AWS credits | Agent Skill or self-hosted MCP (spec 2025-11-25+) |
| [Bee](./bee.md) | $12,000 + meeting | $8,000 | — | Real Bee device or Apple Watch + Bee software |
| [Ring](./ring.md) | $12,000 + meeting | $8,000 | — | Ring APIs/SDKs/simulators/devices |
| [AWS Builder (mini)](./aws-builder.md) | $5,000 + $5K AWS credits + meeting | — | — | Bedrock, AgentCore, SageMaker, Strands, Kiro |
| [Open Source (mini)](./open-source.md) | $5,000 + $5K AWS credits + meeting | — | — | New repo or PR/branch/fork to a public repo |

All winners also get project features. **A project may win at most one track prize + one mini-challenge prize.** That means the strongest strategy is: pick one strong primary track idea, then layer on whichever mini-challenge is nearly free to add (AWS services or an open-source contribution) rather than splitting effort across two primary tracks.

## Submission checklist (applies to every idea in this folder)

- [ ] Public GitHub repo with clear setup/run instructions
- [ ] Demo video, under 3 minutes, on the actual target device/platform, on YouTube or Vimeo
- [ ] Text description of features and functionality
- [ ] Product feedback: tools used, what worked, what didn't, onboarding experience
- [ ] Track + mini-challenge identification
- [ ] Optional: feature requests + friction log (for the bonus)
